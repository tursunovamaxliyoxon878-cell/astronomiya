# Astronomiya 11-sinf — interaktiv darslik

Barcha fayllar bitta joyda (repozitoriya ildizida), papka yaratish shart emas:
- `index.html` — darslik
- `sw.js` — oflayn rejim
- `mavzu_01_ovozli.mp4` … `mavzu_40_ovozli.mp4` — mavzu videolari
- `astronomiya_*_ovozli.mp4` — 3 ta yig'ma video

## GitHub Pages
Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)` → Save.
Sayt `https://<login>.github.io/<repo>/` manzilida ochiladi.

## Imkoniyatlar
- Har mavzu boshida 14 savollik kirish testi, oxirida 10 savollik test, o'sish foizi.
- Videolarda tezlik tanlash va to'xtagan joydan davom ettirish.

## Yig'ma videolar joylashuvi
- 25-mavzu oxirida: 25–32-mavzular videosi
- 33-mavzu oxirida: 33–40-mavzular videosi
- Mundarijadan keyin: barcha 40 mavzu videosi
